# 实现中组件双账号展示

**Status:** `complete`

## What to build

让 iPhone 中尺寸主屏幕组件展示用户从主屏幕已配置账号列表中选择的最多两个具体账号。每个账号形成独立的 Pulse Rail 区域，并在区域内根据渠道显示单环或双环、对应的重置时间，以及一次账号级重置次数。点击某个账号区域进入该账号详情。

## Acceptance criteria

- [x] 中组件按用户选择顺序展示最多两个账号，只有一个账号时布局自然补位，未选择时提示配置；验证：运行空、单账号、双账号、超量和重复选择测试。
- [x] MiniMax + GLM、Codex + SuperGrok、同渠道多账号三种组合均保持账号边界清楚，环和重置时间不会串到另一个账号；验证：运行组合快照测试。
- [x] Codex/SuperGrok 的重置次数有值时在账号区域显示一次，缺失时显示“未提供”，GLM/MiniMax 不产生无意义占位；验证：运行账号级次数展示测试。
- [x] 每个账号区域可独立深链到对应账号，非账号区域回到应用账号列表；验证：检查生成的目标 URL 并在模拟器逐一区域点击。
- [~] Dynamic Type、长账号名、浅色/深色外观下不截断关键百分比或把环挤出边界；固定快照 Preview 和 target 构建已覆盖结构，完整外观矩阵留待实机验收。
