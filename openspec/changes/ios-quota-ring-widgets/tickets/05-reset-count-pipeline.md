# 接通 Codex 与 SuperGrok 账号级重置次数

**Status:** `complete`

## What to build

完成 Codex 与 SuperGrok 剩余可手动重置次数从可信响应、领域快照、持久化到 Widget 展示的端到端路径。次数是账号级信息，在每个账号区域只显示一次，不能挂到某个 5 小时或周额度环，也不能从响应中的明细列表长度或其他字段推算。

SuperGrok 必须先以真实响应证据核实字段含义。如果当前可用响应没有可信次数，保持可选数据并显示“重置次数未提供”，记录证据缺口；不能使用原型中的示意数字冒充真实结果。

## Acceptance criteria

- [x] Codex 的 0、正数、缺失、负数或非法次数均按规则解析并贯穿快照、持久化和 Widget；验证：运行提供商、编码恢复和 Widget 存储测试。
- [x] SuperGrok 的次数来源有响应字段及含义证据；若有则完成同样的端到端解析，若没有则明确记录缺口并保持“未提供”；验证：使用脱敏真实响应或可信夹具运行解析测试并核对集成文档。
- [x] Widget 对支持该概念的账号只显示一个次数徽标，双环账号不会重复显示两次；验证：运行 Codex 与 SuperGrok 单环/双环展示测试。
- [x] 不支持手动重置次数的渠道不显示无意义徽标；验证：运行五渠道展示矩阵测试。
- [x] 不执行任何真实重置操作；验证：检查网络请求仅包含查询，并运行全量 XCTest。
