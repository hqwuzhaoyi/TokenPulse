# 实现大组件四账号展示

**Status:** `complete`

## What to build

让 iPhone 大尺寸主屏幕组件以 2×2 Pulse Rail 网格展示用户从主屏幕已配置账号列表中选择的最多四个具体账号。每个账号保持与小、中组件相同的渠道图标、额度环、重置时间和账号级重置次数语义，并支持从每个可见账号区域进入相应详情。

## Acceptance criteria

- [x] 大组件按用户选择顺序展示最多四个账号，并对 0、1、2、3、4 个选择产生明确且无空洞误导的布局；验证：运行账号数量 Preview/截图矩阵。
- [x] 四账号混排时，单环 MiniMax、双环 GLM/Codex 与单环 SuperGrok 的视觉重量平衡且信息不互相覆盖；验证：使用批准原型中的混合账号数据进行截图对照。
- [x] 系统配置把大组件选择上限限制为四个，重复账号在展示策略中按首次出现去重；验证：检查真实 Widget 编辑页并运行超量/重复选择测试。
- [x] 每个可见账号区域拥有独立深链；验证：断言四个链接目标并在模拟器逐一点击。
- [~] 长账号名、缺失额度、待更新、刷新失败、浅色/深色及大号 Dynamic Type 下仍保留关键数值；状态测试、固定快照 Preview 和 target 构建已覆盖结构，完整外观矩阵留待实机验收。
