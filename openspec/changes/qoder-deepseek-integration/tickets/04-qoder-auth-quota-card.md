# Qoder 国际版授权与双额度卡片

**Status:** `ready-for-agent`

## What to build

用户在 iPhone 添加 Qoder 国际版服务账号，通过浏览器设备授权后由 TokenPulse 直接查询额度。A 原型的账号卡片分别展示个人额度与组织资源包，保留各自的单位、剩余量及可信已用比例，不合并资源包。

设备凭证无法使用参考实现的旧刷新接口自动续期。用户已接受过期后在 iPhone 重新授权并同步新凭证；过期时保留上次额度并在对应卡片提示。先验证真实授权与查询，不能只因参考代码存在就认定可用。

## Acceptance criteria

- [ ] 完成 PKCE 浏览器授权、轮询等待、成功返回、取消、网络中断恢复和授权超时流程，敏感凭证不进入日志或普通配置；验证：授权契约 XCTest 和真实 iPhone 浏览器登录。→ PKCE、轮询、网络恢复和超时 XCTest 已通过；**真实浏览器登录与取消操作未执行，保持未勾选**。
- [ ] 直接向 Qoder 国际版额度接口查询，不依赖 Mac、CLIProxyAPIPlus 管理服务或手机之外的代理；验证：请求测试和真实额度响应核对。→ 请求契约 XCTest 已通过；**真实额度响应未核对，保持未勾选**。
- [ ] 同一提供商的两个账号数据和凭证互相隔离，重启后未过期凭证仍可查询；验证：多账号与安全存储测试。
- [ ] 个人额度和组织资源包分别展示实际返回的数据；缺失资源包不造出零额度，账户级超限状态不错误套用到每个资源包；验证：双资源包、单资源包、空对象和整体超限响应测试。→ 合成响应的双桶、缺失桶、空对象和整体超限 XCTest 已通过；**真实响应未核对，保持未勾选**。
- [x] 数值 0 与 1 不被错误当成布尔值；仅使用已核实含义的比例，无法确认时显示未提供；到期时间不作为重置时间或触发重置通知；验证：原始 JSON 解析测试及提醒测试。
- [x] 可信已用比例沿用现有套餐阈值告警，提醒配置统一在设置；卡片不增加提醒入口；验证：阈值测试与 A 原型对照。
- [ ] 凭证过期或服务拒绝凭证时，在对应卡片内提示重新登录并保留旧额度；重新授权成功后替换凭证、恢复查询、清除错误，不调用已知拒绝设备 token 的旧刷新接口；验证：过期与恢复测试及设备重新授权。→ 过期拒绝与不调用旧刷新接口的 XCTest 已通过；**真实重新授权恢复未执行，保持未勾选**。
- [x] iPhone 构建与相关 XCTest 通过，实际登录/查询结果与未验证项分别记录。
