# Qoder Watch 与小组件

**Status:** `ready-for-agent`

## What to build

Qoder 国际版账号与安全凭证同步后，Watch 独立查询个人额度和组织资源包并分别展示。小组件空间不足时由用户选择展示项，沿用现有账号配置入口；凭证过期后提示去 iPhone 重新授权，新凭证到达后恢复查询。

## Acceptance criteria

- [ ] Watch 获取配置与凭证后，在手机离线时仍直接查询 Qoder；未同步凭证时明确显示等待配置状态；验证：同步测试与真实 Watch 独立查询。
- [ ] Watch 中个人额度与组织资源包分别展示，单位、剩余量、可信比例及到期标签与 iPhone 一致，账号排序与关注设置有效；验证：多账号与双资源包界面操作。
- [ ] iPhone 与 Watch 小组件可选个人额度或组织资源包；选择保留且更新生效，所选项缺失时显示未提供，不静默替换；验证：选择持久化测试与各组件入口操作。→ 选择与双桶分离 XCTest 已通过；**实体组件入口操作未执行，保持未勾选**。
- [x] 到期时间不显示成重置时间，不因时间到达推断额度恢复；账户级超限状态不污染其他资源包数值；验证：到期前后与超限快照测试。
- [ ] Watch 凭证过期时保留旧数据并提示在 iPhone 重新授权；新凭证同步后可恢复独立刷新，不尝试不支持的自动续期；验证：过期、同步替换和恢复测试，配合实际设备重新授权流程。
- [x] 失败仅显示于对应账号页面或组件，保留原采集时间，其他账号正常；验证：多账号部分失败场景。
- [ ] 关键额度、单位与状态在小尺寸、长账号名及辅助功能下可读；验证：各组件尺寸、Watch 页面与 VoiceOver 检查。
- [x] 完整 iOS/watchOS/Widget 构建与相关 XCTest 通过；记录实际设备验证证据及任何仍阻塞验收的项。
