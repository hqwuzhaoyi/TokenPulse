**Blocked by:** 01 — 语言基础与首页首条完整路径

**Status:** complete

**验收范围更新：** 2026-10-13 用户明确指示“跳过这个”，豁免本轮 iPhone 与 Watch 的 VoiceOver 实际听辨及语音导航验收。此项记为用户豁免，未执行、未声称测试通过。已完成的辅助功能标签/AX 检查保留；不豁免普通 Watch 触控、Crown、滚动、表盘宿主或最终中文锁屏复验。 本票其余验收已由既有行为、双语 UI、大字号和 AX 证据覆盖，按更新后的范围关闭。

- [x] 提供商选择页的标题、搜索提示、已有服务分组、空搜索结果及已选状态均可按语言理解；品牌名称不作生硬翻译。
- [x] 保留多语言搜索别名，实际排序、分组和原生字母索引目标一致；点击与拖动索引可到达正确分组。
- [x] 所有 API Key 添加分支中的应用自有字段说明、地区或范围选择、校验、保存成功与失败反馈均支持双语。
- [x] API Key 等常用术语允许保留英文；用户输入的账号名、Key、地址、组织标识和地区身份不因语言变化被改写。
- [x] 用现有凭证和账号测试替身验证一个直接 Key 路径及一个带网关或范围的路径，覆盖成功和失败；不同配置分支的自有文案均有资源覆盖检查。

共同约束：首期仅简体中文与英文，复用现有展示/通知行为测试边界。常用英文术语不算漏翻译；不改变 Provider API、数据身份或授权架构，不自动翻译用户输入与第三方内容。每票完成自身范围的双语行为及可视验证，不能把质量检查全部留给最后一票。
