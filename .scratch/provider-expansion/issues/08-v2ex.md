# 08: V2EX AI Chat 额度接入

**Status:** implemented-awaiting-real-validation

**Type:** integration

**What to build:** 用户输入个人访问 Token，在双端查看 AI Chat 滚动额度及购买的补充包。

**Blocked by:** None (can start immediately)

## Acceptance criteria

- [ ] 5 小时额度与补充包分别展示，不能相加制造总使用率。
- [ ] 未开始的窗口不显示重置倒计时；补充包的到期时间与套餐重置时间明确区分。
- [ ] 完成添加、凭证安全保存、多账号隔离、重新打开后恢复、账号删除与同步；iCloud 关闭时本机可用。
- [ ] iPhone 与 Watch 分别直连提供商查询；Watch 已取得配置和凭证后，不依赖手机或 Mac 在线。
- [ ] 账号卡片、详情、iPhone 小组件和 Watch 展示保持数值、单位、采集时间与过期状态一致；支持演示数据并保持演示与真实账号隔离。
- [ ] 适用的额度告警、重置提醒或低余额提醒沿用现有规则；失败保留旧数据，缺失指标不补零，预计重置不等同于确认恢复。
- [ ] 增加有意义的请求契约、解析边界、账号隔离和提醒行为验证；运行相关测试和完整 unsigned TokenPulse target 构建，覆盖 App、Widgets 与 Watch 资源。
- [ ] 新增图标优先官方资产或既有 Lobe Icons 来源，固定来源版本、记录版权许可，并验证模板渲染与矢量资产。
- [ ] 记录实际账号查询、凭证失效和双端独立刷新证据；没有凭证或设备时准确保留未验收项，模拟响应通过不能代替真实验收。
- [ ] 更新提供商支持范围、登录说明、领域用语与验证边界。

## Implementation evidence (2026-10-02)

Provider.v2ex and direct HTTPS Bearer personal-token quota client added. Five-hour window and permanent extra_usage token packs remain separate. Inactive zero timestamps never become resets; active period_start binds the real window and period_end states reset. Added packs/recharge cannot trigger inferred reset. Provider/key fingerprint isolates cache/reminders across Token replacement. Shared API-key UI/storage/sync/delete flow, demo, widgets and a generic system chat icon are included. Current official help explicitly says packs never expire; no expiry is invented. See docs/v2ex-provider-integration.md.

Passed Swift 6 App module and full new XCTest semantic typecheck, PBX/diff checks. No xcodebuild or simulator used by this worker; root owns test execution and unsigned all-target build. Real Token/device/query/notification/sync and brand vector licensing remain unverified, so acceptance remains open.
