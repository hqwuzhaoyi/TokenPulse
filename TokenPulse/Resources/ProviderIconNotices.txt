Provider icons

Claude, OpenAI, OpenCode, Z.ai, MiniMax and Grok SVG marks are derived from Lobe Icons (https://github.com/lobehub/lobe-icons), via qunqin24/Pulse commit 8d7fd60454ce383dd0a136a30790c1e277f8069b, Sources/Pulse/Resources.

Zhipu mainland reuses the existing ProviderZai mark, and MiniMax International reuses the existing ProviderMiniMax mark. The source commit, copyright, MIT License and vector/template packaging above apply to both regional entries; no new asset is imported.

Qoder and DeepSeek SVG marks are derived from Lobe Icons commit a94750e3f5f8fc33757b839d85030e742284e43a. Their shapes were checked against the official Qoder and DeepSeek site favicons.

The Kimi Code SVG mark is derived from Lobe Icons commit 2e76c48721e91b9aaa40803a0fa2eb8aca7399c4, packages/static-svg/icons/kimi.svg.

The ElevenLabs SVG mark is derived from Lobe Icons (https://github.com/lobehub/lobe-icons) commit 2e76c48721e91b9aaa40803a0fa2eb8aca7399c4, packages/static-svg/icons/elevenlabs.svg. Copyright (c) 2023 LobeHub, MIT License (full text below).

The Poe SVG mark is derived from Lobe Icons commit 79b551cf26aab9ea4ac701fb807160950a5b860f, packages/static-svg/icons/poe.svg, Copyright (c) 2023 LobeHub, MIT License. The official poe-platform/poe-code repository was checked for a reusable provider mark; no suitable licensed mark was found.

The Vercel SVG mark is derived from the official vercel/vercel repository commit c628be7835e03a965b93e9cf9e2bd5ac2acbf5eb, examples/nextjs/public/vercel.svg, Copyright 2017 Vercel, Inc., Apache License 2.0. TokenPulse replaces the white fill with black, adds explicit dimensions and packages it for template rendering; vector paths are unchanged. The applicable full Apache License is included below.

The StepFun SVG mark is derived from Lobe Icons (https://github.com/lobehub/lobe-icons) commit ef22550bbbdc0350e40596ee6e9097024f2eeda7, packages/static-svg/icons/stepfun.svg, Copyright (c) 2023 LobeHub, under the MIT License reproduced below.

The New API SVG mark is derived from Lobe Icons repository https://github.com/lobehub/lobe-icons, commit a94750e3f5f8fc33757b839d85030e742284e43a, asset packages/static-svg/icons/newapi.svg. Copyright (c) 2023 LobeHub, MIT License (reproduced below). The official New API repository primarily supplies a raster brand mark; the existing Lobe Icons vector source is used for template rendering.

The GitHub Copilot SVG mark is derived from Lobe Icons commit 2e76c48721e91b9aaa40803a0fa2eb8aca7399c4, packages/static-svg/icons/githubcopilot.svg. Copyright (c) 2023 LobeHub, MIT License (included below). The official github/copilot.vim repository inspected for an icon did not include an SVG provider mark.

TokenPulse changes: replace currentColor with black for template rendering, set explicit SVG dimensions, and package in an Xcode asset catalog. Vector paths are unchanged.
